## [0.1.0] - 2026-09-13

### Added

- `@kolektiv/brand-core`, `@kolektiv/brand-react`, `@kolektiv/brand-vue`,
  `@kolektiv/brand-svelte`, and `@kolektiv/brand-vanilla`.
- Per-variant components (`IconMark`, `Wordmark`, `ComputingWordmark`, `BuiltByMark`)
  with per-group colour and CSS-only hover colours.
- `theme.css` mapping daisyUI/Tailwind theme tokens onto the brand parts app-wide.
- Docs site (kitchen sink + marks gallery) published to GitHub Pages.
- Publish/release workflows mirroring Keel, publishing to the `brand-npm`
  hosted repository and resolving from the aggregated `npm-public` group.
